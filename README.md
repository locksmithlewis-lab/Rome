# Rise of Rome

A new browser-based Roman combat prototype built from scratch in this repository. The original project repository is not modified.

## Run locally
- Install Node.js 18 or newer.
- Run `npm install`
- Run `npm run dev`
- Open the local Vite URL.

## Build
Run `npm run build`; Vite outputs the deployable site to `dist/`.

## Controls
- WASD: move
- Mouse: look
- Left click: sword attack
- F: shield
- Shift: sprint
- Escape: release mouse

## Current scope
The first playable slice contains a low-poly Roman frontier courtyard, first-person movement, a hostile soldier with basic pursuit/attack behavior, health and stamina, sword hit detection, and a post-victory campaign screen. It is an early foundation, not yet a complete open-world empire simulator.
